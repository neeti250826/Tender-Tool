# Translation brief – Spanish public-tender text → English

Context: public procurement records (El Salvador & Honduras) for clinical laboratory diagnostics, rapid tests, blood bank,
microbiology, pathology, molecular tests and diabetes supplies. Readers are market analysts who don't read Spanish.

## Rules
1. Translate EVERY string fully and faithfully into clear English. Do not summarise, shorten, merge or skip anything –
   long bid texts ("SE SOLICITA… SE OFRECE… MARCA… ORIGEN… VENCIMIENTO…") must be translated in full.
2. Keep unchanged: brand and product names (Wiener, Human, Linear, Spinreact, Architect, cobas, Determine, Bioline, i-STAT…),
   catalogue / model / registration numbers, codes ("CODIGO: 30106468", "CODIGO MERCANCIA ONU: 41116004", "DNM"), process
   numbers ("LP-18/2019", "CM-SESAL-HE-ALAB-36-2026"), quantities, numbers, dates, chemical formulas, units of measure (ml, g, mm).
3. Analyte / test names in standard English lab terms (TGO → AST (TGO), TGP → ALT (TGP), urea nitrogen, glycated haemoglobin, etc.).
   Keep the original abbreviation in brackets when it is not obvious.
4. Use normal sentence case even when the source is all capitals. Keep line structure only where it helps (lists → "; ").
5. If a string is already English, or is only a name/code, return it unchanged.
6. Translate the meaning, not word-for-word; fix obvious typos silently (e.g. "REMATOIDEA" → rheumatoid).
