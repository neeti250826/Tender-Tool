# Pakistan (Sindh) - Sindh PPRA (pprasindh.gov.pk)

`probe.js` loads the portal in headless Chrome and lists BER / evaluation / award links. The portal returns empty replies from outside Pakistan (also via the SG-exit VPN), so no extraction was built. `e.pprasindh.gov.pk/ber` is reported to offer CSV/XLS export once reachable.
